# Company Fundamentals Analysis Skill - Design Spec

## 1. Overview

A TRAE skill that performs comprehensive fundamental analysis for A-share companies. Data is fetched via akshare (East Money source). The skill follows a layered approach: `get_fundamentals` provides a comprehensive overview first, then `get_balance_sheet`, `get_cashflow`, and `get_income_statement` are available for detailed drill-down. The final analysis report is generated by LLM reading the JSON data.

## 2. Directory Structure

```
skills/company-fundamentals/
├── scripts/
│   ├── get_fundamentals.py      # Comprehensive fundamentals data
│   ├── get_balance_sheet.py     # Balance sheet (yearly/quarterly, consolidated/parent)
│   ├── get_cashflow.py          # Cash flow statement (yearly/quarterly, consolidated/parent)
│   ├── get_income_statement.py  # Income statement (yearly/quarterly, consolidated/parent)
│   └── utils.py                 # Shared utilities
├── data/                        # Runtime-generated JSON data (gitignored)
└── SKILL.md                     # Skill definition
```

## 3. Input & Output

### 3.1 Input

- All scripts accept **stock code** (e.g., `600519`) as the primary argument.
- Financial statement scripts accept an optional `--years N` parameter (default: 5).
- Company name to stock code resolution is handled by LLM via `web_search` before calling scripts.

### 4.3 `get_balance_sheet.py` - Balance Sheet

**Usage:** `python scripts/get_balance_sheet.py 600519 --years 5`

**Output:** 4 JSON files (consolidated/parent x yearly/quarterly)

**Key fields per report entry:**
- Report date
- Total assets, total liabilities, total equity
- Current assets, current liabilities
- Cash and equivalents, accounts receivable, inventory
- Fixed assets, intangible assets
- Short-term debt, long-term debt
- And other standard balance sheet items

### 4.4 `get_cashflow.py` - Cash Flow Statement

**Usage:** `python scripts/get_cashflow.py 600519 --years 5`

**Output:** 4 JSON files (consolidated/parent x yearly/quarterly)

**Key fields per report entry:**
- Operating activities: cash inflow, cash outflow, net cash flow
- Investing activities: cash inflow, cash outflow, net cash flow
- Financing activities: cash inflow, cash outflow, net cash flow
- Net change in cash

### 4.5 `get_income_statement.py` - Income Statement

**Usage:** `python scripts/get_income_statement.py 600519 --years 5`

**Output:** 4 JSON files (consolidated/parent x yearly/quarterly)

**Key fields per report entry:**
- Revenue, cost of revenue, gross profit
- Operating expenses: selling, administrative, R&D, financial expenses
- Operating profit, total profit, net income
- EPS (basic, diluted)

## 5. SKILL.md Design

### 5.1 Metadata

```yaml
---
name: company-fundamentals
description: "Analyze A-share company fundamentals using akshare (East Money). Provides comprehensive financial analysis including valuation metrics, financial statements, and generates detailed reports. Use get_fundamentals for overview, then get_balance_sheet/get_cashflow/get_income_statement for detailed analysis."
compatibility: "Python 3.10+, akshare, pandas"
allowed-tools: "read_file write_file execute web_search"
---
```

### 5.2 Workflow Guidance in SKILL.md

```
Step 0: Resolve Stock Code (if user provides company name)
  → LLM uses web_search to find stock code
  → Search query: "{company_name} A股 股票代码"

Step 1: Get Comprehensive Fundamentals (always start here)
  → execute get_fundamentals.py <stock_code>
  → read_file {stock}_fundamentals.json
  → Analyze overview data

Step 2: Drill Down as Needed (optional)
  → If valuation analysis needed → execute get_income_statement.py
  → If debt/liquidity analysis needed → execute get_balance_sheet.py
  → If cash flow quality analysis needed → execute get_cashflow.py
  → read_file the corresponding JSON files

Step 3: Generate Analysis Report
  → LLM synthesizes all gathered data into a comprehensive Markdown report
```

### 5.3 Report Structure (generated by LLM)

1. **Executive Summary** - Key findings and investment thesis
2. **Company Overview** - Business description, industry position
3. **Valuation Analysis** - Current metrics vs historical, peer comparison
4. **Financial Performance** - Revenue/profit trends, margin analysis, ROE/ROA
5. **Financial Health** - Balance sheet strength, debt analysis, liquidity
6. **Cash Flow Analysis** - Operating cash flow quality, FCF, capital allocation
7. **Risks and Opportunities** - Key risks, growth catalysts, industry trends
8. **Conclusion and Recommendation** - Investment thesis summary, actionable insights
9. **Key Metrics Summary Table** - Markdown table organizing all key metrics

## 6. Error Handling

| Scenario | Handling |
|----------|---------|
| Network failure | Retry 3 times with exponential backoff (1s, 2s, 4s). On final failure, mark `"fetch_status": "failed"` in JSON with error message |
| Missing metrics | Set value to `null` (not 0). Add field name to `"missing_fields"` list in JSON |
| Invalid stock code | Raise clear error message with explanation |
| Data anomalies | Log warning. Attempt cleanup; if fails, mark as missing |
